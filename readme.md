# Nelder-Mead Optimization & Visualization

Dieses Repository enthält eine eigenständige Implementierung des **Nelder-Mead-Algorithmus** (Downhill-Simplex-Verfahren) zur heuristischen numerischen Optimierung. 

Als Test- und Visualisierungsumgebung dient die **Himmelblau-Funktion**. Das Projekt demonstriert die praktische Umsetzung mathematischer Optimierungsprobleme in Code sowie die nachvollziehbare Visualisierung von algorithmischen Suchpfaden.
